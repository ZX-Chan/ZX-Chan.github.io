## 连接设备
1. 工作在物理层以下的设备 **无源集线器**
2. 物理层 **中继器** **有源集线器**
3. 物理层和数据链路层 **网桥** **两层交换机**
4. 物理层 数据链路层 网络层 **路由器** **三层交换机**
5. 五层 **网关**
### 无源集线器
- 只是个连接器，连接不同分支，信号冲突点
### 中继器
- 接收信号，在数据变的很弱或者被破坏之前重新生成原始的位模式，然后发送新生成的信号
- 能够扩展局域网的物理长度
- 连接同一局域网的两个分段
- 不能连接采用不同协议的两个局域网
- 转发每一帧，没有过滤能力
- 不是放大器，是再生器
- 中继器的位置很重要，必须放置在信号的每个位被噪声改变之前能到达的位置
### 有源集线器
- 一个多端口的中继器
- 常用于星型拓扑

## 虚拟局域网(VLAN)
- 将局域网内的站点划分成与物理位置无关的逻辑组的技术
- 虚拟局域网其实只是局域网给用户提供的一种服务，并不是一种新型局域网。
- 虚拟局域网限制了接收广播信息的工作站数，使得网络不会因传播过多的广播信息 (即“广播风暴”) 而引起性能恶化。
- [i] VLAN技术有以下优点
- [x] 改善性能
- [x] 简化管理
- [x] 降低成本
- [x] 改善安全性
- [i] 实现VLAN的方法
- 基于交换机接口
	- 最简单、也是最常用的方法
	- 属于在第 1 层划分虚拟局域网的方法
	- 缺点：不允许用户移动
- 基于计算机网卡的 MAC 地址
	- 属于在第 2 层划分虚拟局域网的方法
	- 允许用户移动
	- 缺点：需要输入和管理大量的 MAC 地址。如果用户的 MAC 地址改变了，则需要管理员重新配置VLAN
- 基于协议类型
	- 属于在第 2 层划分虚拟局域网的方法
	- 根据以太网帧的第三个字段“类型”确定该类型的协议属于哪一个虚拟局域网
- 基于 IP 子网地址
	- 属于在第 3层划分虚拟局域网的方法
	- 根据以太网帧的第三个字段“类型”和 IP 分组首部中的源 IP 地址字段确定该 IP 分组属于哪一个虚拟局域网
- 基于高层应用或服务的方法
	- 根据高层应用或服务、或者它们的组合划分虚拟局域网
	- 更加灵活，但更加复杂
